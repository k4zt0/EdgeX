XGB XGT HMI Designer v3 - r004
================================

실행
1. 압축을 새 폴더에 풉니다.
2. RUN.cmd 또는 실행.bat를 실행합니다.
3. Windows .NET Framework 4.x의 csc.exe로 자동 빌드 후 실행됩니다.

v3 추가 기능 - Pro-face식 드래그 이동 / 마우스 크기조절
--------------------------------------------------

[운전 화면 - 배치 편집 v3]
- '배치 편집 ON' 후 원하는 스위치/램프/숫자/텍스트를 마우스로 클릭하면 선택됩니다.
- 선택된 요소에는 상/하/좌/우 및 네 모서리에 총 8개의 크기조절 핸들이 나타납니다.
- 요소의 어느 부분이든 왼쪽 버튼으로 잡아 드래그하면 이동합니다.
- 8개 핸들을 잡아당기면 폭/높이를 마우스로 즉시 조절할 수 있습니다.
- 모서리 핸들: 폭과 높이를 동시에 변경합니다.
- 상/하 핸들: 높이 변경, 좌/우 핸들: 폭 변경.
- 이동/크기조절 중 상단에 X/Y/W/H가 실시간 표시됩니다.
- 마우스를 놓는 순간 편집 탭의 X/Y/폭/높이 값에도 자동 반영됩니다.
- 배치 편집 중에는 스위치/숫자쓰기 명령을 PLC로 보내지 않도록 잠깁니다.
- 빈 화면을 클릭하면 선택이 해제됩니다.
- 저장하려면 '프로젝트 저장'을 누르십시오.

[화면 편집 탭]
- 여러 행 선택 가능
  * Ctrl + 클릭: 개별 여러 행 선택
  * Shift + 클릭: 연속 여러 행 선택
- Ctrl+C : 선택한 요소 복사
- Ctrl+V : 복사한 요소 붙여넣기
- 붙여넣기 할 때 기존 위치에서 20px씩 어긋나게 생성되어 겹쳤는지 쉽게 확인할 수 있습니다.
- '선택 복제 ×N'
  * 현재 선택한 1개 또는 여러 요소를 원하는 수량만큼 한 번에 복제합니다.
  * 예: 스위치 3개 선택 -> ×N에서 5 입력 -> 3개짜리 묶음이 5벌 추가됩니다.
- '스위치 수량 추가'
  * 원하는 개수만 입력하면 새 스위치를 한 번에 생성합니다.
  * M주소는 현재 편집 화면에 있는 가장 큰 M주소 다음 번호부터 자동 증가합니다.
  * 예: 마지막 주소가 M1016이면 5개 추가 시 M1017~M1021 생성.
- 선택 삭제는 여러 행을 한 번에 삭제할 수 있습니다.
- 우클릭 메뉴에서도 복사 / 붙여넣기 / 선택 복제 ×N / 삭제를 사용할 수 있습니다.

[운전 화면 - 배치 편집]
- '배치 편집 ON' 상태에서 카드 제목을 드래그하여 위치 이동.
- 카드 우클릭:
  * 복사
  * 복제
  * 삭제
- 빈 화면 우클릭:
  * '여기에 붙여넣기'
  * 복사한 카드/묶음을 마우스 위치에 붙여넣습니다.
- 운전 화면에서 복제/붙여넣기 한 내용은 편집 탭에도 즉시 반영됩니다.
- 프로젝트 저장을 눌러야 XML에 영구 저장됩니다.

PLC 주소 / 스위치
-----------------
- SWITCH / LAMP: M 또는 P 비트
  예: M1008, M01008, P00120
- NUM_INPUT / NUM_DISPLAY: D WORD
  예: D200, D100
- SWITCH 동작: 토글 / ON / OFF / 순간 / ON/OFF
- Monitor Device를 지정하면 제어 M과 실제 P 출력 상태를 동시에 볼 수 있습니다.

예시
----
1. JOB START 스위치 1개를 설정합니다.
   Device = M01009
   Monitor = P00121
2. 해당 행을 선택하고 Ctrl+C -> Ctrl+V.
3. 새 행의 주소/이름만 바꾸면 동일한 크기와 동작을 가진 새 스위치를 빠르게 만들 수 있습니다.
4. 같은 형식의 스위치가 20개 필요하면 '선택 복제 ×N' 또는 '스위치 수량 추가'를 사용합니다.

주의
----
- PC에서 PLC 쓰기는 상단 'PLC 쓰기 허용'을 체크해야 동작합니다.
- 실제 설비가 움직일 수 있으므로 출력 관련 M 조작은 설비 정지/안전 상태에서 시험하십시오.
- 화면 편집/배치 편집은 PLC 쓰기와 별개이며 프로젝트 저장 전에는 XML에 영구 저장되지 않습니다.


[v4 토글 수정]
- 토글 클릭 시 화면 캐시가 아니라 PLC의 실제 M/P 비트 상태를 즉시 읽고 반전합니다.
- 쓰기 후 30ms 뒤 실제 비트를 재확인합니다.
- 요청값과 READBACK이 다르면 통신 로그에 PLC 래더/다른 쓰기 덮어쓰기 경고를 남깁니다.


[v5 TOGGLE FIX]
- M 스위치 ON/OFF 방식을 %MX 개별 BIT 쓰기에서 M WORD Read-Modify-Write 방식으로 변경.
- 예: M1008 = MW63 bit0. OFF 시 MW63을 읽고 bit0만 0으로 만든 뒤 %MW63에 다시 씀.
- ON도 같은 방식으로 해당 비트만 1로 만듦.
- 쓰기 후 3회까지 실제 M 비트를 재확인함.
- 3회 후에도 원하는 상태가 아니면 PLC 래더가 같은 M 비트를 덮어쓰는 것으로 판단해 오류 메시지를 표시함.


[v6 M ADDRESS FIX]
- XGB M bit address parsing corrected to XG5000 notation: decimal WORD + hexadecimal bit.
- M01008 = MW100 bit8 = %MX1608 (NOT MW63 bit0).
- M switch ON/OFF uses MW100 read-modify-write for M01008, preserving other bits.
- Toggle reads the real PLC bit immediately, then writes the opposite state and verifies readback.
